# AI-Assisted Highlighting for Learning

This repository contains the complete materials developed for the study **AI-Assisted Highlighting for Learning: Comparing Static and Interactive Support in Reading Comprehension**.

The project investigates different forms of reading support and compares their effects on reading comprehension, user experience, and cognitive workload. The experimental system includes three reading support modes:

1. **Manual Highlighting Mode**
2. **AI Main Ideas Support Mode**
3. **Chatbot Support Mode**

This repository includes the source code of the experimental application, the literature review, the study questionnaires, the research paper, anonymized experimental data, and the files used for statistical analysis.

## Repository Structure

### AI_assisted_highlighting_for_learning

Contains the source code of the experimental web application and browser extension.

The system was developed to support the reading comprehension experiment and includes the implementation of the three reading support modes, article presentation, predefined quizzes, interaction tracking, data collection, and result export.

### literature_review

Contains the literature review materials used to support the theoretical background and development of the study.

This folder includes:

- reviewed research papers;
- the literature review spreadsheet;
- supporting documentation.

### questionnaires

Contains the questionnaires and comprehension quizzes used during the experimental study.

The folder includes:

- initial demographic questionnaire;
- comprehension quizzes with answer options;
- final comparative feedback questionnaire;
- SUS and NASA-TLX questionnaires.

### research_paper

Contains the research paper and its source materials.

This folder includes:

- the final research paper in PDF format;
- the LaTeX source files;
- the bibliography;
- the figures used in the paper.

### results

Contains the anonymized experimental data and the files used for statistical analysis.

This includes:

- experimental datasets and original JSON files;
- ANOVA input and output files;
- exported statistical diagrams;
- demographic correlation analysis;
- anonymized participant data.

## Running the Application

## Data and Privacy

All participant data included in this repository are anonymized using participant IDs. No personally identifiable participant information is included in the published experimental datasets.
