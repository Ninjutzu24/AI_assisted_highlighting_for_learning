# Questionnaires

This folder contains the questionnaires and comprehension quizzes used during the experimental study.

## Contents

### `initial_demographic_questionnaire.pdf`

Contains the initial demographic questionnaire completed by participants before the experiment.

### `comprehension_quizzes_with_answer_options.pdf`

Contains the comprehension quizzes and answer options used to assess participants' understanding of the reading materials.

### `final_comparative_feedback_questionnaire.pdf`

Contains the final questionnaire used to collect participants' comparative feedback on the different reading support modes.

### `sus_nasa_questionnaire.pdf`

Contains the System Usability Scale (SUS) and NASA Task Load Index (NASA-TLX) questionnaires used to evaluate system usability and perceived cognitive workload.

## Purpose

These questionnaires were used to collect participant demographics, assess reading comprehension, evaluate the usability of the system, measure perceived cognitive workload, and gather comparative feedback on the different reading support modes.
